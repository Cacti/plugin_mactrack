# MacTrack 4.8: device collection fixes and the MacTrack name restored

Historical release, published 2024-10-16. [Current releases](https://github.com/Cacti/plugin_mactrack/releases).

This maintenance release restores the MacTrack name in the interface and fixes collection problems affecting TP-Link and Aruba devices, device imports and debug runs.

## Highlights

- Restore the MacTrack name after the earlier Device Tracking branding.
- Correct TP-Link active-VLAN collection and an Aruba OS-CX scanner variable.
- Fix adding devices to Cacti and PHP errors when nonresponding devices are scanned in debug mode.

## Compatibility and upgrade checks

The [metadata shipped in v4.8](https://github.com/Cacti/plugin_mactrack/blob/v4.8/INFO) declares a minimum Cacti version of **1.2.14**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_mactrack/blob/v4.8/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. Expect the interface to use MacTrack rather than Device Tracking.
2. After upgrading, test one affected TP-Link or Aruba device and confirm device imports and nonresponding-device debug runs complete as expected.
