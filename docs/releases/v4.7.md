# MacTrack 4.7: PHP 8 fixes and better DNS process control

Historical release, published 2024-04-20. [Current releases](https://github.com/Cacti/plugin_mactrack/releases).

MacTrack 4.7 focuses on PHP 8 runtime issues and control of reverse-DNS processing. The original announcement also collects the changes made in the intervening 4.3–4.6 versions.

## Highlights

- Reduce PHP 8 problems involving undefined variables and array keys.
- Improve control of the DNS resolving process.
- Retain the bundled earlier history covering additional device types, address retention, scanning and notification fixes in the detailed list below.

## Compatibility and upgrade checks

The [metadata shipped in v4.7](https://github.com/Cacti/plugin_mactrack/blob/v4.7/INFO) declares a minimum Cacti version of **1.2.14**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_mactrack/blob/v4.7/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, inspect a normal scan and reverse-DNS run, and check the Cacti/PHP logs for the runtime errors addressed here.
2. The original announcement specifically thanks @xmacan and the wider testing community; those acknowledgments are preserved below.
