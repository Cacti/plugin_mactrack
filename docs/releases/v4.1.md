# MacTrack 4.1: translation support and clearer poller messages

Historical release, published 2018-03-31. [Current releases](https://github.com/Cacti/plugin_mactrack/releases).

This maintenance release improves translation support and resolves site-removal and poller-message problems.

## Highlights

- Make it easier for contributors to provide translated interface text.
- Fix site removal and clarify ambiguous MacTrack poller messages.

## Compatibility and upgrade checks

The [metadata shipped in v4.1](https://github.com/Cacti/plugin_mactrack/blob/v4.1/INFO) declares a minimum Cacti version of **1.1.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_mactrack/blob/v4.1/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, inspect the interface in the configured language and check a poller run for understandable status messages.
