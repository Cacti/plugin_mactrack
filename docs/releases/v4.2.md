# MacTrack 4.2: Cisco 802.1x and DHCP snooping visibility

Historical release, published 2018-03-31. [Current releases](https://github.com/Cacti/plugin_mactrack/releases).

MacTrack 4.2 adds Cisco collection paths and a dedicated Dot1x Sessions tab, alongside fixes to scanning, DNS resolution and vendor imports.

## Highlights

- Collect Cisco 802.1x sessions and DHCP snooping information.
- View Dot1x sessions in their own tab and see a port-name column in the IP Address view.
- Use theme-specific styling and the expanded wiki documentation.
- Fix scanner function detection, resolver SQL errors and OUI imports that removed existing records when an import failed.

## Compatibility and upgrade checks

The [metadata shipped in v4.2](https://github.com/Cacti/plugin_mactrack/blob/v4.2/INFO) declares a minimum Cacti version of **1.1.10**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_mactrack/blob/v4.2/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. After upgrading, verify Cisco session/IP collection and the new tab on a device that supports those tables.
2. Check that port names appear in the IP Address view and that the configured OUI import completes before relying on updated vendor labels.
