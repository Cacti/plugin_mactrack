# MacTrack 4.0: Cacti 1.x integration and interface updates

Historical release, published 2018-03-31. [Current releases](https://github.com/Cacti/plugin_mactrack/releases).

MacTrack 4.0 updates the plugin for the Cacti 1.x generation, adds internationalization and refreshes interface behavior and packet counters.

## Highlights

- Add internationalization and updated Spanish translations.
- Move interface backgrounds into CSS and use jQuery for DOM handling.
- Restore device Save and MAC port-name filtering controls, and fix site-query and interface-status display problems.
- Replace deprecated non-unicast packet counters with multicast and broadcast counters.

## Compatibility and upgrade checks

The [metadata shipped in v4.0](https://github.com/Cacti/plugin_mactrack/blob/v4.0/INFO) declares a minimum Cacti version of **1.1.1**. Follow the [documentation for this tag](https://github.com/Cacti/plugin_mactrack/blob/v4.0/README.md) for the matching installation and configuration steps.

Before replacing plugin files, back up the plugin/local configuration and its database together. Apply migration instructions only when they match the version you are upgrading from.

1. Review any external reports that depend on the old non-unicast counter names.
2. After upgrading, verify device editing, site/interface views and the configured language.
